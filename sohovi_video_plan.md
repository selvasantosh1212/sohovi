# Sohovi Video Plan — Sequenced Upload Backlog

This file is **headings and sequence only — no scripts.** It answers one question: in what order should a solo founder, who has never posted a video, film and upload the 124 videos already identified?

- Full scripts for the 74 numbered PV videos (PV1–PV74) live in `video_tutorials.md`, under the "PRIORITY VIDEO SET."
- The 50 items marked "new — needs script" have no script yet; they're title/angle candidates only, pulled from the FAQ and keyword banks.
- Title/description keyword variants live in `sohovi_keywords.md` — pull from there when writing the actual YouTube title/description for each upload.
- This sequence was built from two research passes: `video_inventory.md` (tiering and gating notes on the 74 scripted videos) and `shortform_candidates.md` (the 50 new short-form candidates), cross-checked against `audience_pain_points_research.md` (tier/channel-allocation logic) and `reddit_post.md` (segment priority order and posting-cadence philosophy).

Work top to bottom. Every one of the 74 scripted videos and all 50 new candidates appears exactly once below — this is the actual backlog, not a curated top 10.

## Practical notes

- **Cadence:** 1–2 uploads/week is realistic for a solo operator with limited time — matches the same "don't dump it all at once" philosophy used for the Reddit plan. At that pace, 124 videos is roughly 15–24 months of content, which is fine — the point is visible, sustained momentum, not a sprint.
- **Fixed anchor:** #36, the Sohovi Platform Demo (PV1), is the one video worth protecting in place — it's both the flagship overview and the landing-page video. It's flexible by a handful of positions (earlier if the founder wants the conversion asset live sooner; later if more reps are wanted first) but shouldn't land in the first ~20 or past the ~50 mark.
- **Fixed block:** #38–55, the Learn tutorial series (PV2–15), should stay together and in order — it's an onboarding sequence, not standalone content, and only makes sense after the Hero Demo and some top-of-funnel awareness exist.
- **Flexible/reorderable:** almost everything else, especially the "General" mechanic shorts (PV16–31) and the new FAQ/keyword/checklist shorts — these have no dependency on each other or on product state, so swap them around freely to fill a week when a heavier deep-dive isn't ready.
- **Gating issue to fix before filming — #81 (PV44):** the script frames this as a pure "Free plan, no card" video for a Non-profit audience, but it builds the rule using the AI Builder, which is explicitly Pro-only elsewhere in the same script set (PV38). A Free-tier viewer couldn't actually follow along as written — rewrite the rule-building step to use a Free-tier method, or add an honest Pro-plan callout, before shooting.
- **Other undisclosed gating worth a quick pass, not a blocker:** #40 (PV4, Business-only connectors) and #36 (PV1, Business-only catalog scoring) demo paid features with no on-screen plan disclaimer — every other Pro/Business feature elsewhere in the backlog gets one. Cheap to add a text-overlay callout when editing.
- **Cheapest-to-produce videos overall:** the 50 new FAQ/keyword/checklist shorts and the PV52–69 segment shorts — no screen recording needed, good to keep a few in reserve as "filler" for weeks when a scripted deep-dive isn't finished in time.
